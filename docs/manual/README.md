# SmartCW manual

SmartCW is a USB-C iambic keyer, CW trainer and CW interface for radios and SDR software, made by RF.Guru. This manual describes firmware 2.4.2: the System page shows which version your SmartCW runs, and [smartcw.app/update](https://smartcw.app/update) brings it up to date.

| Chapter | For |
| --- | --- |
| [1. Getting started](01-getting-started.md) | What is in the box, the connectors and LEDs, the first ten minutes |
| [2. Keying](02-keying.md) | Paddles, straight key and bug, speed, memories, beacon, tune, the PTT button, your fist |
| [3. Connecting a radio](03-radio.md) | The CW jack, the Radio Interface, key line or audio with PTT, sidetone, QSK timing |
| [4. The web interface](04-web-interface.md) | Live, Settings, System, sidetone in the browser |
| [5. The trainer](05-trainer.md) | Every exercise, the Koch method, the fist analyzer |

| [7. Reference](07-reference.md) | Every setting in `config.txt`, every `!` command |
| [8. Updates and troubleshooting](08-updates-and-troubleshooting.md) | Firmware updates, boot modes, what the LEDs tell you, common problems |

Developers find the protocols and the web API in [INTEROP.md](../../INTEROP.md), and the source overview in the [README](../../README.md).
